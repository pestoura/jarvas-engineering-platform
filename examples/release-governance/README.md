# JDS-002 examples

These examples are executable fixtures for the release-maintenance validator.

- `changes/CHG-BRIDGE-001.yaml` demonstrates a bug discovered during a release-candidate validation campaign.
- `validation/VAL-BRIDGE-2-0-GA.yaml` demonstrates a campaign that records the defect, links its remediation and remains not ready for promotion until the campaign is explicitly accepted.

The Bridge identifiers are illustrative in this central repository. Product repositories retain their own canonical records.
